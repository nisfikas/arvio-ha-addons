# Arvio HA add-ons

Home Assistant OS add-on repository for [Arvio](https://github.com/nisfikas/arvio) lab.

## Install

1. HA → **Settings → Add-ons → Add-on store → ⋮ → Repositories**
2. Add: `https://github.com/nisfikas/arvio-ha-addons`
3. Refresh → open **Arvio Agent** → **Install** → **Start**
4. Options: `cloud_url` = your Arvio API (lab Mac), `serial` = hub serial

Local UI: `http://homeassistant.local:8099/`
